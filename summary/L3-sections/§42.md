# §42 — Not a psychological process but an order: the same order as "Why?"

[Overview](../L0-overview.md) › [Part V: Practical Reasoning](../L1-parts.md#part-v-practical-reasoning) › [G13: §§41–43](../L2-sections/G13-s41-43-the-order-of-practical-reasoning.md) › **§42** · [← §41](§41.md) · [§43 →](§43.md)

*Pages: from p. 79 (1963 2nd ed. / Harvard 2000 pagination). Anscombe's contents line, paraphrased: setting practical reasonings out in full looks absurd. The point of doing so is not to describe what goes on in the mind but to describe an order. It is the same order that appeared in the discussion of what "the intentional action" was.*

## In one sentence
Writing out every step of a practical syllogism would be absurd as a report of anyone's thinking. Aristotle's account describes instead "an order which is there" whenever actions are done with intentions. It is the same means–end order that the series of "Why?" questions revealed in the pumping example.

## Summary
Anscombe faces an obvious objection to everything since §33. If one spells out the practical reasoning behind an everyday action in full, with every premise and step, the result has an "absurd appearance" (p. 79; Campbell 2022). People seldom, if ever, go through such steps. Her answer is that the account was never meant to describe psychological processes. It describes an order: the practical syllogism sets out "an order which is there whenever actions are done with intentions" (p. 80; Frey, Small, Holton).

She then identifies that order with one already met (contents line). In §§23–26 the pumping man's action fell under a series of descriptions (moving his arm, operating the pump, replenishing the water supply, poisoning the inhabitants), each related to the next by "Why?" and its answer. The practical syllogism displays the *same* order, from the other end. Thompson (1998) states this crisply: the order of descriptions elicited by "Why?" is "the reverse of" the order in which an agent reasoning from end to means would set them out. Wiland & Driver call the two "equivalent", and Frey glosses them as the "Why?" (A→D) and "How?" (D→A) directions.

So "practical reasoning" names a structure in intentional action itself, not a mental event that precedes and causes it. Piñeros Glasscock & Tenenbaum cite §42 for the claim that the agent's grasp of this order is not a separate occurrence. This is what lets §§44–48 return to practical knowledge. Since §33 said practical knowledge is to be understood through practical reasoning, practical knowledge can now be read as knowledge of this order *in* the action.

## Main claim(s)
- Setting out practical reasoning in full looks absurd if read as a mental record (§42, contents line; p. 79).
- Aristotle's account describes an order present whenever actions are done with intentions, not psychological processes (p. 80; Frey, Small).
- That order is the same as the A–D order of descriptions of "the intentional action" (§§23–26) (contents line; Thompson 1998: in reverse).

## Examples
- The pumping example of §§23–26 is invoked as the same order (contents line).
- *Commentators' examples, not Anscombe's:* Small's redecorating and paint can (Small 2020).

## Objections and alternatives Anscombe considers
- The objection that real agents do not go through these steps, so the syllogism falsifies psychology. She replies that it is not psychology (§42, contents line).

## In the secondary literature
- [Thompson 1998](../../sources/secondary/thompson-1998-rep-anscombe.md) — the order of descriptions elicited by "Why?" is "the reverse of" the order articulated by the agent reasoning from end to means (§42, with §26).
- [Small 2020](../../sources/secondary/small-2020-action-practical-knowledge.md) — the "order which is there whenever actions are done with intentions" (§42). Going through all the steps would be very rare. The agent knows the whole order, i.e. what she is doing, how and why, even without deliberation. Small asks how basic actions, which lack the means–end order, are known.
- [Campbell 2022](../../sources/secondary/campbell-2022-practical-knowledge-practical-truth.md) — the "absurd appearance" of syllogisms set out in full (p. 79). Practical reasoning is an abstract order elicited by "Why?", not a prior mental process.
- [Frey 2016](../../sources/secondary/frey-2016-action-practical-knowledge-good.md) — not a psychological process (p. 80). The order is "there whenever…". "What is first in the order of intention is last in the order of execution."
- [Wiland & Driver 2022](../../sources/secondary/wiland-driver-2022-sep-anscombe.md) — end–means deliberation and the "because" order of descriptions are equivalent. The order "really exists among events".
- [Millgram 2026](../../sources/secondary/millgram-2026-intention-of-intention.md) — not a description of mental process. Practical reasoning is identical with intention's order. Anscombe is anti-psychologistic.
- [Holton 2025](../../sources/secondary/holton-2025-cambridge-lectures.md) — cites §42 for Anscombe's method ("depth grammar"). Against Wiseman, he insists that she is still talking about individual actors and what they think.
- [Piñeros Glasscock & Tenenbaum 2023](../../sources/secondary/pineros-glasscock-tenenbaum-2023-sep-action.md) — cite §42 for the agent's grasp not being a separate occurrence, which is defensible. They *also* cite §42 for "I was not aware I was doing that", which looks like a mis-citation for §6.
- [Schwenkler 2019](../../sources/secondary/schwenkler-2019-guide.md) — 5.5 "'… an order which is there …'" (§§42–43). The account is of an order, not of psychological "mechanisms from which action results" (p. 148, via Pellegrini).
- [Wilson & Shpall 2012](../../sources/secondary/wilson-shpall-2012-sep-action.md) — no engagement with this order or with §§33–44.

## Notes and uncertainties
- No † claims. The Summary rests on the contents line and the cited sources. Anscombe's own wording of the absurd-appearance passage is not reproduced in the sources and is paraphrased here only via Campbell.
- Elsewhere, e.g. "Practical Inference" (1989, per Small), Anscombe repeats the point that practical inference does not describe actual mental processes.
